# URSS - Particle-Physics-Data-Classification

Comparing a classical algorithm (RBF SVM) against a quantum algorithm (QVSM) in classifying signals and noise within large particle data sets.

The goal is to try and preserve as many signals as possible and get rid of background noise, to then analyse the meaning of these particle interactions and see how we can learn from it. 
We will be using machine learning methods (decision trees) to build these algorithms. 

All done via Python
